多包裹邮件处理工具

一、启动
双击桌面的“多包裹邮件处理工具”快捷方式。启动窗口会隐藏，Google Chrome 会自动打开本地页面：http://127.0.0.1:8788
也可以双击文件夹中的“启动工具.bat”；它会调用同一个隐藏启动器。

二、使用流程
1. 上传云仓导出的 .xlsx 文件。
2. 下载“ERP下载订单号.xlsx”。浏览器会下载到你的默认下载位置；程序文件夹的 outputs 目录用于存放已生成的示例/历史输出。系统只处理以下四个来源：THRYVIX_US_US、XOCN_US、VYNELITO_US、ZEIINPA_US。此文件使用参考云仓表作为格式模板，Shipment 工作表只保留五列：订单号、来源（Ship From）、物流类型、物流单号、邮件内容；同一订单的多个物流号按原始顺序换行排列。
3. 使用订单号从 ERP 手动下载包含邮箱的 .xlsx 文件。
4. 上传 ERP 文件。
5. 下载“发邮件最终数据_多包裹.xlsx”或“多包裹订单人工复核.xlsx”。最终邮件文件以程序文件夹中的“发邮件8.17-1.xlsx”为模板，只替换收件邮箱、邮件内容、发件邮箱，不改变模板的颜色、样式、列宽、行高和单元格大小。

第一阶段的结果按原始云仓记录中订单号首次出现的顺序排列，不会按订单号重新排序；同一订单的物流号仍按原始出现顺序去重。

三、移动
可以移动整个“MultiPackageEmailTool”文件夹到其他磁盘或目录。
请始终移动整个文件夹，不要只移动启动工具.bat。
电脑需要安装 Node.js，并且 node 命令在系统 PATH 中。
移动后，原桌面快捷方式可能失效，需要在新位置重新创建快捷方式。

四、数据与安全
文件只在本机处理，不连接云仓、ERP 或邮箱服务，也不会自动发送邮件。
关闭服务窗口后，本轮上传到临时目录的文件会清理。
最终发送表固定为：收件邮箱、邮件内容、发件邮箱。
发件邮箱按订单来源自动匹配：VYNELITO_US 使用 13288070760@163.com；ZEIINPA_US 使用 3777612514@qq.com；XOCN_US 使用 15889560452@163.com；THRYVIX_US_US 使用 17322503251@163.com。
