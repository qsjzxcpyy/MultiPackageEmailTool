# 多包裹邮件处理工具

本地 Node.js 工具，用于读取云仓和 ERP 导出的工作簿，整理同一订单的多个包裹、承运商和物流号，并生成可供人工复核或发送前检查的邮件数据表。

## 启动

Windows 用户可以使用目录中的启动脚本：

- `启动工具.bat`
- `启动工具隐藏.vbs`

也可以直接运行：

```powershell
node server.mjs
```

启动器会打开本地网页，具体端口以启动脚本和终端输出为准。

## 使用流程

1. 上传云仓导出的 `.xlsx` 工作簿。
2. 导入包含邮箱信息的 ERP 工作簿。
3. 工具按订单号合并物流记录，并保留原始出现顺序。
4. 下载最终邮件数据或人工复核数据。

混合承运商和多物流号的处理规则位于 `multi_package_email.mjs`，页面资源位于 `web/`。

## 开发与检查

- 核心处理逻辑：`multi_package_email.mjs`
- 本地 HTTP 服务：`server.mjs`
- 检查脚本：`internal/checks/`
- 历史输出和上传文件目录：`outputs/`

运行检查前请根据项目实际 Node.js 版本安装依赖。上传的订单、库存、邮箱和导出工作簿只应在本机临时目录中处理，不要继续提交真实业务数据或发件凭证。
